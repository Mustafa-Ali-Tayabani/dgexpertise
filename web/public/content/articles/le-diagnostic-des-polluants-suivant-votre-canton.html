Avant toute intervention, la législation Suisse impose un diagnostic des polluants du bâtiment afin de protéger les occupants, les intervenants et l’environnement. Amiante, plomb, PCB, HAP ou encore HBCD : ces substances dangereuses sont encore présentes dans de nombreux bâtiments.

Pourquoi réaliser un diagnostic des polluants avant-travaux ?

Les polluants du bâtiment peuvent représenter un risque majeur pour la santé lorsqu’ils sont manipulés ou dégradés lors de travaux. Sans diagnostic préalable :

  • les fibres d’amiante peuvent être libérées dans l’air.
  • les fibres d’amiante peuvent être libérées dans l’air.
  • les PCB peuvent polluer durablement l’environnement.

👉 Un diagnostic permet d’anticiper ces risques et d’éviter :

  • l’arrêt de chantier.
  • des coûts imprévus.
  • des sanctions légales.

Quels diagnostics sont obligatoires selon votre canton ?

Diagnostic des polluants à Genève

Le canton de Genève impose les diagnostics suivants : amiante, plomb, PCB, HAP, HBCD.

👉 Genève applique une réglementation stricte pour sécuriser les travaux.

Diagnostic des polluants à Vaud

Dans le canton de Vaud, les diagnostics requis sont : l’amiante et seulement l’amiante.

Diagnostic des polluants dans les autres cantons en Suisse romande

Dans les cantons comme Fribourg, Neuchâtel ou Valais : amiante, plomb, PCB, HAP.

👉 Une analyse globale est fortement recommandée avant travaux.

Les principaux diagnostic des polluants du bâtiment

Diagnostic amiante avant-travaux

L’amiante a été utilisé massivement jusqu’en 1991. Aujourd’hui classé cancérigène, il est présent dans de nombreux matériaux : faux plafonds, colles, revêtements de sol, isolations…

👉 Le diagnostic amiante est obligatoire avant travaux sur les bâtiments construits avant 1991.

Diagnostic plomb avant-travaux

Le plomb était utilisé dans les peintures jusqu’en 2005. Lors de travaux (ponçage, décapage…), il peut être libéré sous forme de poussières toxiques.

👉 Un diagnostic permet de sécuriser les interventions

Diagnostic PCB

Les PCB sont des polluants chimiques utilisés dans certains matériaux et équipements jusqu’à leur interdiction en Suisse en 1986. On peut encore en retrouver dans des joints, mastics, peintures ou anciens équipements techniques.

Diagnostic HAP

Les HAP sont présents dans : le goudron, bitume, bois traités. Ils présentent des risques cancérigènes importants.

Diagnostic HBCD

L’HBCD est un retardateur de flamme présent dans certains isolants en polystyrène (EPS, XPS), notamment dans les façades ou toitures.

👉 Il présente des risques pour la santé et l’environnement, notamment pour les femmes enceintes.

Quelles sont vos obligations légales ?

Avant toute intervention, il faut :

  • identifier les polluants.
  • informer les entreprises qui vont réaliser les travaux.
  • garantir la sécurité du chantier.

👉🏼 En cas de non-respect :

  • sanctions administratives.
  • arrêt du chantier en cours.
  • surcoûts importants.

Les erreurs fréquentes à éviter ?

  • commencer les travaux sans diagnostic des polluants.
  • sous-estimer les polluants.
  • choisir un prestataire non certifié.
  • ne pas respecter les normes cantonales.
